# apps-script/Code.gs

이 파일은 백업용입니다. 실제로 실행되는 코드가 아닙니다.

진짜 코드는 Google Apps Script 편집기(script.google.com)에 있습니다. 여기 있는 `Code.gs`를 고쳐도 배포에는 전혀 반영되지 않으니, 수정할 땐 반드시 Apps Script 편집기에서 직접 고치고 "배포 관리 → 새 버전"으로 배포한 다음, 이 파일에도 동일하게 옮겨 적어 최신 상태로 맞춰주세요.

`assets/site.js`의 `BRIDGE_URL`이 현재 배포된 Apps Script 웹앱 주소를 가리켜야 합니다. 배포 주소가 바뀌면 `site.js`도 같이 업데이트해야 합니다.
